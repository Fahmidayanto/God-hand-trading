MSA Step 1: Validasi CHoCH & Urutan

Memvalidasi CHoCH aktif terbaru sebelum titik swing baru (HH/LL). Mesin berhenti pada CHoCH pertama yang ditemukan saat pencarian mundur; CHoCH berlawanan yang lebih baru membatalkan arah setup lama.

  • 1. Logika Validasi Sekuens • Fungsi: _has_recent_choch(direction, max_lookback=10)
    • Iterasi mundur: events[1:max_lookback] — memeriksa hingga 9 event sebelum HH/LL.
    • CHoCH Aktif: CHoCH pertama yang ditemukan saat iterasi mundur menjadi satu-satunya penentu arah setup.
    • Bullish Sekuens: CHoCH Bullish aktif mendahului pembentukan HH.
    • Bearish Sekuens: CHoCH Bearish aktif mendahului pembentukan LL.
  • 2. Ilustrasi Lookback 10 Event (Bukan 10 Candle)
    // Event = kejadian struktur pasar (CHoCH/BoS/HH/LL)
    // Satu event bisa terbentuk setelah puluhan candle berlalu

    [0] HH   ← sedang dievaluasi (e1)
    [1] HL    engine mundur ...
    [2] CHoCH Bullish ← CHoCH aktif terbaru, result = True ✅
    [3] LL
    [4] BoS    ← kalau ini ditemukan dulu → BATAL ❌
    ...
    [9] (batas akhir lookback — CHoCH kadaluarsa)

  • 4. Aturan Gugurnya Siklus (Sequence Hygiene) • BoS Ditemukan Duluan: Jika ditemukan event BoS sebelum CHoCH saat iterasi mundur, fungsi langsung kembalikan False — siklus CHoCH dianggap sudah selesai.
    • Opposite CHoCH Lebih Baru: Jika HH sedang diuji tetapi CHoCH aktif terbaru Bearish, hasil langsung False. Mesin tidak melanjutkan pencarian ke CHoCH Bullish yang lebih lama.
    • Lookback Habis: Jika sudah iterasi 9 event tanpa CHoCH ditemukan, fungsi kembalikan False — CHoCH kadaluarsa.
  • 5. Contoh Pembatalan Arah Lama
    [0] HH sedang dievaluasi
    [1] CHoCH Bearish ← CHoCH aktif terbaru
    [2] CHoCH Bullish ← arah lama, tidak diperiksa lagi

    _has_recent_choch("Bullish") = false

        a) High - Low
        b) |High - Close_sebelum|
        c) |Low - Close_sebelum|

    b) |1526.50 - 1525.10| = 1.40
    c) |1524.80 - 1525.10| = 0.30

ML Step 3: Prediksi MFE & MAE

Memprediksi batas keuntungan maksimum (MFE) dan potensi kerugian floating maksimum (MAE) secara paralel menggunakan dual XGBoost Regressor.

  • 1. Prediksi MFE (Maximum Favorable Excursion) Memprediksi seberapa jauh harga emas (XAUUSD) dapat bergerak searah transaksi sebelum mengalami pembalikan besar. Membaca mfe_features dari metadata model, men-scale via mfe_scaler, dan memprediksi target MFE lewat mfe_model.
    Input Fitur Utama MFE:
    • distance_to_last_hh_pips: Jarak ke swing high teratas (Resistansi alami).
    • h1_trend_aligned: Keselarasan arah tren jam (H1).
    • body_ratio: Kekuatan/ketebalan badan candle trigger.

    Contoh Kasus (CHoCH Bullish):
    Jarak HH = 42.1 pips, Trend H1 = Searah (1.0), Body Ratio = 0.78.
    → Scaler memproses fitur → Model MFE memprediksi **3.50 ATR** (Potensi profit maksimal).
  • 2. Prediksi MAE (Maximum Adverse Excursion) Memprediksi batas floating minus terdalam yang mungkin dialami sebelum harga bergerak searah profit. Membaca mae_features dari metadata model, men-scale via mae_scaler, dan memprediksi target MAE lewat mae_model.
    Input Fitur Utama MAE:
    • distance_to_last_ll_pips: Jarak ke swing low terbawah (Support alami/Stop Loss).
    • atr_14: Skala volatilitas/noise pasar saat ini (M15).
    • session_priority: Jam sesi trading (Sesi NY/London memiliki volatilitas MAE berbeda).

    Contoh Kasus (CHoCH Bullish):
    Jarak LL = 24.5 pips, ATR15 = 2.4 pips, Sesi NY Aktif (3.0).
    → Scaler memproses fitur → Model MAE memprediksi **1.80 ATR** (Resiko floating minus maksimal).
  • Contoh Hasil Prediksi (Kasus CHoCH Bullish)
    Output Mentah Model XGBoost (Skala ATR):
    • predicted_mfe: 3.50 (Potensi naik s.d 3.5x ATR15)
    • predicted_mae: 1.80 (Resiko floating minus s.d 1.8x ATR15)

ML Step 4: Denormalisasi ATR

Mengonversi nilai prediksi skala ATR kembali ke satuan harga/pips riil berdasarkan nilai ATR14 saat ini.

  • 1. Logika Denormalisasi Model regresi versi v8 melatih target dalam bentuk rasio terhadap ATR14 (misal: mfe_target / atr_14) agar model stabil di berbagai kondisi volatilitas. Saat prediksi selesai, nilai rasio dikalikan kembali dengan ATR14 pasar terkini.
  • 2. Batas Nilai Wajar (Constraint) Memastikan nilai MFE & MAE hasil denormalisasi tidak negatif dengan rumus pembatas: predicted_mfe = max(0.0, predicted_mfe) dan predicted_mae = max(1.0, predicted_mae).
  • Contoh Denormalisasi (Kasus CHoCH Bullish)
    Data Volatilitas & Konversi Harga:
    • atr_14 M15 Terkini: 2.40 USD (24 pips)
    • Prediksi MFE Mentah: 3.50 → Denormalisasi: 3.50 * 2.40 = 8.40 USD (84 pips)
    • Prediksi MAE Mentah: 1.80 → Denormalisasi: 1.80 * 2.40 = 4.32 USD (43.2 pips)

ML Step 5: Uji R:R & Sinyal

Menguji kelayakan transaksi berdasarkan rasio Risk/Reward dinamis terhadap ambang batas (threshold).

  • 1. Uji Rasio Reward-to-Risk (R:R) Rasio keuntungan dibanding kerugian dinilai dengan membagi hasil denormalisasi MFE terhadap MAE: expected_rr = predicted_mfe / predicted_mae.
  • 2. Pengambilan Keputusan Sinyal Jika expected_rr ≥ threshold (misal: 1.50), sinyal struktur awal (BUY/SELL) disetujui. Jika di bawah itu, sinyal dibatalkan dan diset ke HOLD.
  • 3. Kalkulasi Skor Confidence (Tingkat Keyakinan) Skor keyakinan berkisar antara 0.0 s.d 1.0. Jika disetujui: min(1.0, expected_rr / 2.0). Jika diset ke HOLD: max(0.0, min(1.0, 1.0 - expected_rr / threshold)).
  • Contoh Keputusan Akhir (Kasus CHoCH Bullish)
    Hasil Pengujian Transaksi:
    • Ambang Batas (Threshold): 1.50
    • Skor R:R Terhitung: 8.40 / 4.32 = 1.944 (Lolos Uji ≥ 1.50)
    • Arah Sinyal Final: BUY (Sesuai Struktur SMC)
    • Skor Keyakinan (Confidence): min(1.0, 1.944 / 2.0) = 0.972 (97.2%)

Risk Management Agent

Penjaga gerbang manajemen modal dan rasio keuntungan-kerugian (Risk/Reward).

  • Peran Sizing Menentukan lot size berdasarkan risk percentage. Tidak masuk dalam penjumlahan voting konsensus.
  • Hak Istimewa Memiliki Hak Veto Mutlak. Jika rasio RR kurang dari 1:1.5 atau risiko per trade melebihi batas (misal: max 2% balance), sinyal langsung dibatalkan (veto ke HOLD).

Risk Step 1: Klasifikasi Confidence Tier

Mengelompokkan confidence hasil Consensus Engine ke dalam 4 tingkatan risiko yang menentukan berapa persen saldo dipertaruhkan.

Risk Step 2: Kalkulasi Lot Size

Menghitung ukuran posisi (lot) berdasarkan persentase risiko tier, saldo akun, estimasi jarak SL, dan pip value.

  • Rumus Lot = RiskUSD / (SL_pips * PipValue)
    Di mana: RiskUSD = Saldo * (RiskPct / 100)
  • Batasan • Minimum lot: 0.01
    • Maximum lot: 10.0
    • Pembulatan ke kelipatan 0.01 terdekat
  • Contoh Kalkulasi (STRONG Tier)

    • Risk Pct: 1.5% → RiskUSD = $1,000 * 1.5% = $15.00
    • Estimasi SL: ATR(7.2) * SL_Mult(4.0) = 28.8 pips
    • PipValue: $10/lot (XAUUSD)
    • Lot = $15 / (28.8 * $10) = 0.05 lot

Risk Step 3: Dynamic SL/TP

Menghitung jarak Stop Loss dan Take Profit dinamis berbasis ATR, regime volatilitas, sesi trading, dan faktor jam.

  • 1. Deteksi Volatility Regime • LOW: ATR < Q1 (6.0) → SL = 2.5x ATR, TP = 3.5x ATR
    • NORMAL: Q1 ≤ ATR < Q3 (8.5) → SL = 4.0x ATR, TP = 5.0x ATR
    • HIGH: ATR ≥ Q3 (8.5) → SL = 6.0x ATR, TP = 7.0x ATR
  • 2. Session Adjustment • Asia: 0.85x (volatilitas rendah)
    • London: 1.2x (puncak volatilitas)
    • NY: 1.15x (aktivitas tinggi)
    • London-NY Overlap: 1.3x (volatilitas tertinggi)
  • 3. Hour Factor Faktor koreksi per jam (0-23). Contoh: jam 8 (London open) = 1.4x, jam 4 (Asia quiet) = 0.9x.
  • Contoh SL/TP (NORMAL, London, 09:00)
    • ATR M15: 7.2 (NORMAL regime)
    • Vol Adjustment = Hour(1.3) * Session(1.2) = 1.56
    • SL distance = 7.2 * 4.0 * 1.56 = 44.93 pips
    • TP distance = 7.2 * 5.0 * 1.56 = 56.16 pips
    • Entry BUY @ 2350.00:
      SL = 2350.00 - 44.93 = 2305.07
      TP = 2350.00 + 56.16 = 2406.16
    • R:R = 56.16 / 44.93 = 1.25

Risk Step 4: Validasi Risiko

  • Daftar Validasi • Lot Size: Harus antara 0.01 dan 10.0 lot
    • SL Distance: Tidak boleh melebihi 500 pips (hard limit)

Consensus Engine

Mesin voting tertimbang untuk menggabungkan hasil keputusan semua agen.

  • Rumus Konsensus Skor = (MS * 0.25 + ML * 0.40 + Sent * 0.20) / 0.85
  • Ambang Batas Diperlukan minimal skor 60% (0.60) dari bobot total (0.85) untuk menyetujui transaksi (BUY/SELL) dan meneruskannya ke Risk Management Agent. Jika di bawah itu, keputusan akhir adalah HOLD.
  • Contoh Kalkulasi Nyata (CHoCH Bullish)
    • Skor MSA (BUY, 0.850) → 0.25 * 0.850 = 0.2125
    • Skor ML (BUY, 0.900) → 0.40 * 0.900 = 0.3600
    • Skor Sent(BUY, 0.815) → 0.20 * 0.815 = 0.1630
    • Total Skor = 0.2125 + 0.3600 + 0.1630 = 0.7355
    • Persentase Konsensus = 0.7355 / 0.850 = 86.5% (Modus: BUY)
    → Status: APPROVED (Skor 86.5% ≥ 60%)

Sentiment Step 1: Sentimen Berita

Mengevaluasi sentimen berita XAUUSD terbaru menggunakan model LLM dengan cadangan kata kunci (keyword-based).

  • Kombinasi Kumulatif & Deduplikasi Berita digabungkan secara akumulatif dari slot-slot sebelumnya di hari yang sama dengan filter deduplikasi (_dedup_news exact + fuzzy ≥ 0.85).
  • Fungsi Keyword & Negation Memindai kata negasi (seperti no, not, despite) dalam jendela 3 kata sebelum kata kunci Bullish/Bearish untuk menyaring berita palsu/tidak relevan.
  • Penyusutan Waktu (Recency Decay) Berita baru memiliki bobot 1.0, sedangkan berita lama menyusut secara eksponensial (waktu paruh 12 jam). Berita di luar 24 jam dibuang.

    • Primary LLM Provider: AgentRouter (GLM-5.2) | Fallback #2: Groq API (qwen/qwen3.6-27b)
    • Replay Anchor Slot: 09:00 UTC (Akumulasi slot 00, 03, 06, 09)

    → Sentimen: BULLISH | Bobot Waktu: 0.89
    • Headline: "Stronger dollar limits gold upside" (6 jam lalu)
    → Sentimen: BEARISH | Bobot Waktu: 0.70
    • Skor Sentimen Akhir: +0.19 (Bullish Lemah)

Sentiment Step 2: Analisis Kalender

Mendeteksi agenda rilis data ekonomi makro yang dapat memicu volatilitas tinggi pada pergerakan harga emas.

  • Event Berpengaruh Tinggi (High Impact) Memonitor event krusial: NFP (Non-Farm Payroll), FOMC (Fed Rate Decision), CPI (Inflation Data), GDP, dan Powell Speech.
  • Pengecekan Waktu (Proximity) Menghitung jarak waktu (selisih jam dan menit) antara jadwal rilis event dengan waktu perdagangan saat ini.
  • Penarikan Anchor saat Structure Event Saat terjadi Structure Event (CHoCH/BoS/HH/LL) di jam simulasi (misal 10:15 UTC), sistem mengambil data sentimen dari slot 3-harian sebelum terdekat (slot_hour ≤ event_hour, yaitu slot 09:00 UTC).

Sentiment Step 3: Penyesuaian Skor

Menyesuaikan tingkat keyakinan (confidence) transaksi berdasarkan keselarasan sentimen berita dan kedekatan event.

  • Penyesuaian Keselarasan (Alignment) Mencocokkan arah sinyal dari MSA dengan sentimen berita:
    • Searah (Sinyal BUY + Berita Bullish): Skor confidence ditambah (Boost).
    • Berlawanan (Sinyal BUY + Berita Bearish): Skor confidence dikurangi (Penalty).
  • Soft Proximity Penalty (Penyusutan Halus) Mengurangi confidence secara gradual saat mendekati event ekonomi penting:
    • Jarak ~6 jam: -10% dari confidence.
    • Jarak ~1 jam: -25% dari confidence.
    • Jarak <30 menit: -50% dari confidence (maksimal penalti total -15%).
  • Contoh Penyesuaian (Kasus CHoCH Bullish)
    • Sinyal Awal MSA: BUY | Confidence: 0.850
    • Sentimen Berita: BULLISH (+0.19) → Boost: +0.050
    • Event: NFP akan rilis dalam 6 jam → Penalti Halus: -10% (-0.085)
    • Penyesuaian Bersih: +0.050 - 0.085 = -0.035
    • Keyakinan Baru: 0.850 - 0.035 = 0.815

Sentiment Step 4: Veto High Impact

Membatalkan seluruh transaksi ketika waktu rilis berita penting sudah terlalu dekat.

  • Kondisi Veto Keras (Hard Veto) Jika event penting berlabel avoid_trading: True (seperti FOMC atau NFP) dijadwalkan rilis dalam rentang kurang dari 30 menit, transaksi dibatalkan demi keamanan.
  • Hasil Veto Sinyal akhir langsung ditolak dan dialihkan menjadi HOLD, dengan skor keyakinan dipaksa turun menjadi 0.0.
  • Contoh Eksekusi Veto
    • Sinyal MSA: BUY | Event NFP: 15 menit lagi.
    → Veto Keras: TERPICU (Jarak < 30 menit)
    → Keputusan Akhir: HOLD | Confidence: 0.000

  • Aturan Veto Lunak & ML Bypass Jika keyakinan MSA rendah (< 0.60) tetapi ML menghasilkan sinyal aktif dengan expected R:R yang kuat (≥ 1.35), veto dilewati (Bypassed) dan sinyal tetap diijinkan berjalan.

  • Tingkat Konsensus • ≥ 95% → Unanimous
    • ≥ 80% → Strong
    • ≥ 60% → Moderate
    • ≥ 50% → Weak
    • < 50% → No Consensus
