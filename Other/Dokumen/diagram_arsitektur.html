MetaTrader 5 & EA

CSV Watcher Service

Python background service berbasis watchdog yang memantau perubahan folder direktori CSV secara berkala.

  • File targets LLHHBOSData_*.csv, Backtest_Results_*.csv, MarketData_M15_*.csv
  • Hybrid Trigger Begitu mendeteksi struktur baru, ia langsung meluncurkan sinkronisasi ke LanceDB dan men-trigger keputusan Orchestrator secara instan.

LanceDB Vector Database

Menyimpan data historis terintegrasi dalam bentuk representasi vektor (16-D untuk pola, 12-D untuk transaksi, 8-D untuk market).

  • Lokasi Database python/valuecell/data/lancedb
  • Metode Sinkronisasi (Opsi B) Data dibaca dari NeonDB (relational), divalidasi dan dihitung EMA200/ATR-nya oleh Pandas, kemudian di-insert ke LanceDB secara real-time.

Orchestrator Agent

Mengoordinasi aktivitas analisis pasar dan mendistribusikan data ke seluruh sub-agen.

  • Cara Kerja Menerima pemicu (hybrid: instan dari Watcher atau polling 1 menit), memanggil modul sub-agen untuk melakukan analisis secara paralel, lalu mengirim hasilnya ke Consensus Engine.

Market Structure Agent

Menganalisis pergerakan harga berbasis konsep Smart Money Concepts (SMC) secara obyektif.

  • Bobot Vote 25% dari total konsensus.
  • Tugas Utama Mengidentifikasi titik tertinggi/terendah (HH, LL), perubahan karakter harga (CHoCH), penembusan struktur (BoS), serta area imbalance (FVG) atau Order Block (OB).

ML Prediction Agent

Validator berbasis kecerdasan buatan untuk menguji keandalan sinyal struktur.

  • Bobot Vote 40% dari total konsensus.
  • Algoritma XGBoost Classifier (di-training pada data historis performa backtest). Menilai probabilitas kesuksesan struktur pasar yang terdeteksi sebelum dieksekusi.

Risk Management Agent

Penjaga gerbang manajemen modal dan rasio keuntungan-kerugian (Risk/Reward).

  • Bobot Vote 15% dari total konsensus.
  • Hak Istimewa Memiliki Hak Veto Mutlak. Jika rasio RR kurang dari 1:1.5 atau risiko per trade melebihi batas (misal: max 2% balance), sinyal langsung dibatalkan (veto ke HOLD).

Sentiment Agent

Mengintegrasikan sentimen makro dan rilis kalender ekonomi ke dalam keputusan trading.

  • Bobot Vote 20% dari total konsensus.
  • Sumber Data News RSS Feed (sentimen berita Emas) & Kalender Ekonomi. Mematikan eksekusi transaksi secara otomatis 30 menit sebelum dan sesudah berita penting berlabel *High Impact* (P0/Red Folder).

Consensus Engine

Mesin voting tertimbang untuk menggabungkan hasil keputusan semua agen.

  • Rumus Konsensus Skor = (MS * 0.25) + (ML * 0.40) + (Risk * 0.15) + (Sent * 0.20)
  • Ambang Batas Diperlukan minimal skor 60% (0.60) untuk menyetujui transaksi (BUY/SELL). Jika di bawah itu, keputusan akhir adalah HOLD.

Execution Agent

Mengirimkan sinyal transaksi final dan mengelola lot serta posisi aktif.

  • Fungsi Mengirimkan sinyal ke file instruksi eksekusi, memantau ticket transaksi, memantau batas maksimum lot harian, dan melacak status drawdown akun secara berkala.
