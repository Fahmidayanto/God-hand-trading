  • Tugas Utama Mengidentifikasi titik tertinggi/terendah (HH, LL), perubahan karakter harga (CHoCH), penembusan struktur (BoS), serta area imbalance (FVG) atau Order Block (OB).

MSA Step 1: Validasi CHoCH & Urutan

Memvalidasi bahwa sebelum terbentuknya titik swing baru (HH/LL), memang telah terjadi pembalikan tren awal (CHoCH) yang valid.

  • Fungsi Validasi _has_recent_choch(direction, max_lookback=10)
  • Aturan Sekuens • Bullish Setup: CHoCH Bullish aktif diikuti pembentukan HH.
    • Bearish Setup: CHoCH Bearish aktif diikuti pembentukan LL.
  • Pencegahan Konflik Jika ditemukan BoS lama di tengah sekuens, siklus CHoCH sebelumnya dianggap selesai dan dibatalkan agar tidak tertukar dengan arah setup baru.

MSA Step 2: Mengunci Level Breakout

Mengunci koordinat harga tertinggi (HH) atau terendah (LL) sebagai level ambang batas pemicu BoS.

  • Penyimpanan Level Referensi • Bullish: self._pending_hh_price = price
    • Bearish: self._pending_ll_price = price
  • Fungsi Ambang Batas Level ini menjadi batas mutlak untuk lilin candle M15 di masa depan. Konfirmasi BoS hanya sah jika harga penutupan (close) menembus melampaui level referensi ini.

MSA Step 3: Kemiripan Pola (LanceDB)

Pencarian pola historis ke database vektor LanceDB untuk mengekstrak statistik performa BoS masa lalu.

  • Query Pencocokan Vektor self.pattern_matcher.find_similar_patterns() (16-Dimensi Vektor)
  • Parameter Pencocokan • Event: BoS | Arah: Bullish / Bearish
    • Rasio Jarak Harga terhadap EMA200 M15
    • Sesi Trading: London / NewYork / Asia
    • Konteks: prior_choch = True
  • Statistik yang Diambil • Jumlah Sampel: total_count
    • Win Rate Historis: win_rate (%)
    • Rata-rata Keuntungan: avg_profit (Pips)

MSA Step 4: Initial Confidence & Boost

Kalkulasi skor keyakinan awal setup sebelum candle penembusan (BoS) terjadi.

  • Skor Keyakinan Dasar initial_conf = 0.40 (Status masih potensi setup)
  • Tabel Penyesuaian Win Rate (Sampel >= 5)
    • Win Rate ≥ 75%: +0.30 Boost (Conf: 0.70)
    • Win Rate 60% s/d 74%: +0.20 Boost (Conf: 0.60)
    • Win Rate 45% s/d 59%: +0.10 Boost (Conf: 0.50)
    • Win Rate < 45%: -0.10 Penalty (Conf: 0.30)

MSA Step 5: PENDING_SETUP & Pre-Signal

Mengunci bukti setup, melakukan transisi status state machine, dan menyiagakan sub-agen lainnya.

  • State Machine Transition self._phase = AgentPhase.PENDING_SETUP
  • Identitas Unik Setup Hash SHA256: setup_id (berdasarkan Simbol, Timeframe, Level Harga, dan Timestamp).
  • Payload Pre-Signal (Warmup) MSA mengembalikan signal: "HOLD" dengan status PENDING_SETUP - menunggu BoS. Orchestrator menggunakan payload ini untuk memicu warmup pada ML Prediction Agent dan Sentiment Agent agar komputasi siap sebelum lilin BoS terjadi.

ML Prediction Agent

Validator berbasis kecerdasan buatan untuk menguji keandalan sinyal struktur.

  • Bobot Vote 40% dari total konsensus.
  • Algoritma XGBoost Classifier (di-training pada data historis performa backtest). Menilai probabilitas kesuksesan struktur pasar yang terdeteksi sebelum dieksekusi.

ML Step 1: Inisialisasi & Harga

Inisialisasi harga transaksi awal untuk pengujian filter XGBoost.

  • Harga Entri (entry_price) Nilai harga masuk (entri) diambil dari harga close candle M15 terakhir pada bar saat ini.
  • Data Bar (OHLCV) Data market bar terkini (Open, High, Low, Close, Volume) digunakan sebagai basis inisialisasi.
  • Rute Pengiriman Data Data OHLCV ini dikirimkan langsung oleh Orchestrator secara paralel ke MSA dan ML Agent saat event terpicu (bukan dikirim dari MSA ke ML Agent).
  • Contoh Nilai (Kasus CHoCH Bullish)
    Event terdeteksi: CHoCH Bullish @ M15
    • Entry Price: 1525.23
    • Data Bar (M15):
    Open: 1525.00 | High: 1526.50 | Low: 1524.80 | Close: 1525.23 | Vol: 1200

ML Step 2: Rekayasa Fitur

Mengekstrak 19+ fitur input dari pergerakan harga melalui FeatureEngineer.

  • 1. Market Structure Menganalisis jarak umur BoS/CHoCH (jam), arah tren, dan keselarasan indikator SMC.
  • 2. H1 Trend (High Timeframe) Keselarasan harga dibanding EMA200 H1, nilai ATR H1, dan rasio volume H1.
    Kalkulasi ATR14 H1:
    • True Range (TR): Nilai maksimum dari:
        a) High - Low
        b) |High - Close_sebelum|
        c) |Low - Close_sebelum|
    • h1_atr_14: Simple Moving Average (SMA) dari 14 nilai TR terakhir (dalam dollar/point).
    • Konversi Pips (Emas): 1 pip = 0.1 USD, sehingga nilai 8.2 USD setara dengan 82 pips.
    Contoh Penghitungan TR 1 Candle:
    Data Candle H1 Terkini: High=1526.50, Low=1524.80, Close_sebelum=1525.10
    a) 1526.50 - 1524.80 = 1.70
    b) |1526.50 - 1525.10| = 1.40
    c) |1524.80 - 1525.10| = 0.30
    → TR = max(1.70, 1.40, 0.30) = 1.70 USD
  • 3. Price Action (M15) Mengukur kekuatan momentum via body_ratio candle, volume ratio, dan ATR15.
  • 4. Sesi & Waktu Trading Jam, hari, prioritas sesi pasar, serta status biner keaktifan sesi London/NY/Overlap.
  • 5. Jarak Swing (Pips) Mengukur jarak absolut harga entri ke swing HH (Highest High) dan LL (Lowest Low) terdekat.
  • Contoh Penerapan Lengkap (19 Fitur - Kasus CHoCH Bullish)
    [A] Market Structure Features:
    • last_bos_age_hours: 3.5 (BoS terdeteksi 3.5 jam lalu)
    • last_choch_age_hours: 0.0 (Terjadi di bar saat ini)
    • choch_to_bos_hours: 3.5 (Jarak waktu antar struktur)
    • last_bos_direction: 1.0 (Bullish)
    • last_choch_direction: 1.0 (Bullish)
    • bos_choch_aligned: 1.0 (Ya / Searah)

    [B] H1 Trend Features:
    • h1_trend_aligned: 1.0 (Searah tren H1)
    • h1_above_ema200: 1.0 (Harga di atas EMA200 H1)
    • h1_atr_14: 8.2 (Pips volatilitas H1)
    • h1_vol_ratio: 1.25 (Volume di atas rata-rata)

    [C] Price Action Features (M15):
    • body_ratio: 0.78 (Badan candle tebal / 78%)
    • vol_ratio: 1.85 (Volume pemicu 1.85x rata-rata)
    • atr_14: 2.4 (Pips volatilitas M15)

    [D] Time & Session Features:
    • hour_of_day: 15.0 (Pukul 15:00 waktu server)
    • day_of_week: 2.0 (Hari Rabu / Mid-week)
    • session_priority: 2.0 (Sesi New York / US)
    • is_london: 1.0 (Sesi London Aktif)
    • is_ny: 1.0 (Sesi NY Aktif)
    • is_overlap: 1.0 (Sesi Overlap Aktif)

    [E] Swing Distance Features:
    • distance_to_last_ll_pips: 24.5 (Jarak ke Swing Low terdekat)
    • distance_to_last_hh_pips: 42.1 (Jarak ke Swing High terdekat)

ML Step 3: Prediksi MFE & MAE

Memprediksi batas keuntungan maksimum (MFE) dan potensi kerugian floating maksimum (MAE) secara paralel menggunakan dual XGBoost Regressor.

  • 1. Prediksi MFE (Maximum Favorable Excursion) Memprediksi seberapa jauh harga emas (XAUUSD) dapat bergerak searah transaksi sebelum mengalami pembalikan besar. Membaca mfe_features dari metadata model, men-scale via mfe_scaler, dan memprediksi target MFE lewat mfe_model.
    Input Fitur Utama MFE:
    • distance_to_last_hh_pips: Jarak ke swing high teratas (Resistansi alami).
    • h1_trend_aligned: Keselarasan arah tren jam (H1).
    • body_ratio: Kekuatan/ketebalan badan candle trigger.

    Contoh Kasus (CHoCH Bullish):
    Jarak HH = 42.1 pips, Trend H1 = Searah (1.0), Body Ratio = 0.78.
    → Scaler memproses fitur → Model MFE memprediksi **3.50 ATR** (Potensi profit maksimal).
  • 2. Prediksi MAE (Maximum Adverse Excursion) Memprediksi batas floating minus terdalam yang mungkin dialami sebelum harga bergerak searah profit. Membaca mae_features dari metadata model, men-scale via mae_scaler, dan memprediksi target MAE lewat mae_model.
    Input Fitur Utama MAE:
    • distance_to_last_ll_pips: Jarak ke swing low terbawah (Support alami/Stop Loss).
    • atr_14: Skala volatilitas/noise pasar saat ini (M15).
    • session_priority: Jam sesi trading (Sesi NY/London memiliki volatilitas MAE berbeda).

    Contoh Kasus (CHoCH Bullish):
    Jarak LL = 24.5 pips, ATR15 = 2.4 pips, Sesi NY Aktif (3.0).
    → Scaler memproses fitur → Model MAE memprediksi **1.80 ATR** (Resiko floating minus maksimal).
  • Contoh Hasil Prediksi (Kasus CHoCH Bullish)
    Output Mentah Model XGBoost (Skala ATR):
    • predicted_mfe: 3.50 (Potensi naik s.d 3.5x ATR15)
    • predicted_mae: 1.80 (Resiko floating minus s.d 1.8x ATR15)

ML Step 4: Denormalisasi ATR

Mengonversi nilai prediksi skala ATR kembali ke satuan harga/pips riil berdasarkan nilai ATR14 saat ini.

  • 1. Logika Denormalisasi Model regresi versi v8 melatih target dalam bentuk rasio terhadap ATR14 (misal: mfe_target / atr_14) agar model stabil di berbagai kondisi volatilitas. Saat prediksi selesai, nilai rasio dikalikan kembali dengan ATR14 pasar terkini.
  • 2. Batas Nilai Wajar (Constraint) Memastikan nilai MFE & MAE hasil denormalisasi tidak negatif dengan rumus pembatas: predicted_mfe = max(0.0, predicted_mfe) dan predicted_mae = max(1.0, predicted_mae).
  • Contoh Denormalisasi (Kasus CHoCH Bullish)
    Data Volatilitas & Konversi Harga:
    • atr_14 M15 Terkini: 2.40 USD (24 pips)
    • Prediksi MFE Mentah: 3.50 → Denormalisasi: 3.50 * 2.40 = 8.40 USD (84 pips)
    • Prediksi MAE Mentah: 1.80 → Denormalisasi: 1.80 * 2.40 = 4.32 USD (43.2 pips)

ML Step 5: Uji R:R & Sinyal

Menguji kelayakan transaksi berdasarkan rasio Risk/Reward dinamis terhadap ambang batas (threshold).

  • 1. Uji Rasio Reward-to-Risk (R:R) Rasio keuntungan dibanding kerugian dinilai dengan membagi hasil denormalisasi MFE terhadap MAE: expected_rr = predicted_mfe / predicted_mae.
  • 2. Pengambilan Keputusan Sinyal Jika expected_rr ≥ threshold (misal: 1.50), sinyal struktur awal (BUY/SELL) disetujui. Jika di bawah itu, sinyal dibatalkan dan diset ke HOLD.
  • 3. Kalkulasi Skor Confidence (Tingkat Keyakinan) Skor keyakinan berkisar antara 0.0 s.d 1.0. Jika disetujui: min(1.0, expected_rr / 2.0). Jika diset ke HOLD: max(0.0, min(1.0, 1.0 - expected_rr / threshold)).
  • Contoh Keputusan Akhir (Kasus CHoCH Bullish)
    Hasil Pengujian Transaksi:
    • Ambang Batas (Threshold): 1.50
    • Skor R:R Terhitung: 8.40 / 4.32 = 1.944 (Lolos Uji ≥ 1.50)
    • Arah Sinyal Final: BUY (Sesuai Struktur SMC)
    • Skor Keyakinan (Confidence): min(1.0, 1.944 / 2.0) = 0.972 (97.2%)

Risk Management Agent

Penjaga gerbang manajemen modal dan rasio keuntungan-kerugian (Risk/Reward).

  • Peran Sizing Menentukan lot size berdasarkan risk percentage. Tidak masuk dalam penjumlahan voting konsensus.
  • Hak Istimewa Memiliki Hak Veto Mutlak. Jika rasio RR kurang dari 1:1.5 atau risiko per trade melebihi batas (misal: max 2% balance), sinyal langsung dibatalkan (veto ke HOLD).

Risk Step 1: Klasifikasi Confidence Tier

Mengelompokkan confidence hasil Consensus Engine ke dalam 4 tingkatan risiko yang menentukan berapa persen saldo dipertaruhkan.

  • Tabel Tier • STRONG (≥ 80% confidence) → Risiko 1.5% saldo
    • GOOD (65-80%) → Risiko 1.0% saldo
    • WEAK (50-65%) → Risiko 0.5% saldo
    • NO_TRADE (< 50%) → Ditolak, lot = 0
  • Contoh Klasifikasi
    • Consensus confidence: 0.865 (86.5%)
    • Tier: STRONG (karena ≥ 0.80)
    • Risk pct yang digunakan: 1.5%

Risk Step 2: Kalkulasi Lot Size

Menghitung ukuran posisi (lot) berdasarkan persentase risiko tier, saldo akun, estimasi jarak SL, dan pip value.

  • Rumus Lot = RiskUSD / (SL_pips * PipValue)
    Di mana: RiskUSD = Saldo * (RiskPct / 100)
  • Batasan • Minimum lot: 0.01
    • Maximum lot: 10.0
    • Pembulatan ke kelipatan 0.01 terdekat
  • Contoh Kalkulasi (STRONG Tier)
    • Saldo: $1,000
    • Risk Pct: 1.5% → RiskUSD = $1,000 * 1.5% = $15.00
    • Estimasi SL: ATR(7.2) * SL_Mult(4.0) = 28.8 pips
    • PipValue: $10/lot (XAUUSD)
    • Lot = $15 / (28.8 * $10) = 0.05 lot

Risk Step 3: Dynamic SL/TP

Menghitung jarak Stop Loss dan Take Profit dinamis berbasis ATR, regime volatilitas, sesi trading, dan faktor jam.

  • 1. Deteksi Volatility Regime • LOW: ATR < Q1 (6.0) → SL = 2.5x ATR, TP = 3.5x ATR
    • NORMAL: Q1 ≤ ATR < Q3 (8.5) → SL = 4.0x ATR, TP = 5.0x ATR
    • HIGH: ATR ≥ Q3 (8.5) → SL = 6.0x ATR, TP = 7.0x ATR
  • 2. Session Adjustment • Asia: 0.85x (volatilitas rendah)
    • London: 1.2x (puncak volatilitas)
    • NY: 1.15x (aktivitas tinggi)
    • London-NY Overlap: 1.3x (volatilitas tertinggi)
  • 3. Hour Factor Faktor koreksi per jam (0-23). Contoh: jam 8 (London open) = 1.4x, jam 4 (Asia quiet) = 0.9x.
  • Contoh SL/TP (NORMAL, London, 09:00)
    • ATR M15: 7.2 (NORMAL regime)
    • Vol Adjustment = Hour(1.3) * Session(1.2) = 1.56
    • SL distance = 7.2 * 4.0 * 1.56 = 44.93 pips
    • TP distance = 7.2 * 5.0 * 1.56 = 56.16 pips
    • Entry BUY @ 2350.00:
      SL = 2350.00 - 44.93 = 2305.07
      TP = 2350.00 + 56.16 = 2406.16
    • R:R = 56.16 / 44.93 = 1.25

Risk Step 4: Validasi Risiko

Memvalidasi semua parameter risiko terhadap batas keamanan keras. Jika satu saja gagal, transaksi langsung diveto ke HOLD.

  • Daftar Validasi • Lot Size: Harus antara 0.01 dan 10.0 lot
    • SL Distance: Tidak boleh melebihi 500 pips (hard limit)
    • Total Risiko: Tidak boleh melebihi 5.0% dari saldo per transaksi
  • Contoh Validasi Gagal
    • Lot = 0.20, SL = 300 pips, PipValue = $10
    • Risk USD = 0.20 * 300 * $10 = $600
    • Saldo = $1,000 → Risk pct = 60%
    • Hasil: DITOLAK (melebihi batas 5%)
  • Contoh Validasi Lolos
    • Lot = 0.05, SL = 28.8 pips, PipValue = $10
    • Risk USD = 0.05 * 28.8 * $10 = $14.40
    • Saldo = $1,000 → Risk pct = 1.44%
    • Hasil: APPROVED (< 5%)

Risk Step 5: Output Final

Menghasilkan paket data lengkap yang dikirimkan ke Execution Agent untuk mengeksekusi order di MT5.

  • Data yang Dikirim • approved: true/false
    • lot_size: Ukuran posisi final
    • entry_price, sl_price, tp_price
    • sl_distance_pips, tp_distance_pips
    • rr_ratio: Rasio reward/risk
    • risk_pct, risk_usd
    • potential_profit, potential_loss
    • tier, volatility_regime, session
  • Contoh Output Lengkap
    • approved: true
    • signal: BUY | tier: STRONG
    • lot_size: 0.05
    • entry: 2350.00 | SL: 2305.07 | TP: 2406.16
    • rr_ratio: 1.25
    • risk: 1.44% ($14.40)
    • potential_profit: $28.08
    • potential_loss: $14.40

Consensus Engine

Mesin voting tertimbang untuk menggabungkan hasil keputusan semua agen.

  • Rumus Konsensus Skor = (MS * 0.25 + ML * 0.40 + Sent * 0.20) / 0.85
  • Ambang Batas Diperlukan minimal skor 60% (0.60) dari bobot total (0.85) untuk menyetujui transaksi (BUY/SELL) dan meneruskannya ke Risk Management Agent. Jika di bawah itu, keputusan akhir adalah HOLD.
  • Contoh Kalkulasi Nyata (CHoCH Bullish)
    • Skor MSA (BUY, 0.850) → 0.25 * 0.850 = 0.2125
    • Skor ML (BUY, 0.900) → 0.40 * 0.900 = 0.3600
    • Skor Sent(BUY, 0.815) → 0.20 * 0.815 = 0.1630
    • Total Skor = 0.2125 + 0.3600 + 0.1630 = 0.7355
    • Persentase Konsensus = 0.7355 / 0.850 = 86.5% (Modus: BUY)
    → Status: APPROVED (Skor 86.5% ≥ 60%)

Consensus Input: Market Structure

Menerima parameter arah sinyal dan skor keyakinan awal dari analisis struktur pasar SMC.

  • Parameter yang Diterima • signal: Arah sinyal awal ("BUY"/"SELL"/"HOLD").
    • confidence: Skor keyakinan awal (0.0 s.d 1.0) dari SMC.
  • Rumus Bobot Voting MSA MSA memiliki hak voting sebesar 25% (bobot 0.25) dari total bobot konsensus. Kontribusi voting dihitung dengan: skor = 0.25 * confidence.
  • Contoh Kontribusi (Kasus CHoCH Bullish)
    • Arah Sinyal MSA: BUY
    • Confidence MSA: 0.850
    → Kontribusi Voting: 0.25 * 0.850 = 0.2125

Consensus Input: ML Prediction

Menerima parameter validasi XGBoost dan rasio keuntungan-kerugian dinamis.

  • Parameter yang Diterima • signal: Sinyal teruji ("BUY"/"SELL"/"HOLD").
    • confidence: Skor keyakinan XGBoost regresi.
    • expected_rr: Rasio MFE/MAE dinamis.
  • Logika Soft Veto Bypass Jika sinyal MSA bernilai HOLD karena keyakinan rendah (< 0.60), tetapi ML mendeteksi sinyal aktif dengan expected R:R yang kuat (≥ 1.35), veto MSA dilewati (bypassed) dan sinyal tetap diproses.
  • Rumus Bobot Voting ML ML memiliki bobot terbesar yaitu 40% (bobot 0.40). Kontribusi voting dihitung dengan: skor = 0.40 * confidence.
  • Contoh Kontribusi (Kasus CHoCH Bullish)
    • Arah Sinyal ML: BUY | Expected R:R: 1.944 (Lolos bypass jika MSA lemah)
    • Confidence ML: 0.900
    → Kontribusi Voting: 0.40 * 0.900 = 0.3600

    • final_confidence: Skor keyakinan yang disesuaikan boost/degradasi.
  • Rumus Bobot Voting Sentiment Sentiment memiliki hak voting sebesar 20% (bobot 0.20). Kontribusi voting dihitung dengan: skor = 0.20 * confidence.
  • Contoh Kontribusi (Kasus CHoCH Bullish)
    • Arah Sinyal Sent: BUY
    • Confidence Sent: 0.815 (Telah dikurangi penalti rilis event NFP)
    → Kontribusi Voting: 0.20 * 0.815 = 0.1630

  • Daily Anchor Slots (3 Jam Replay Engine) Pada mode simulasi/replay, berita dievaluasi per slot 3 jam (00, 03, 06, 09, 12, 15, 18, 21 UTC). Skor LLM dihitung sekali per slot dan di-reuse untuk semua event pada rentang tersebut.
  • Kombinasi Kumulatif & Deduplikasi Berita digabungkan secara akumulatif dari slot-slot sebelumnya di hari yang sama dengan filter deduplikasi (_dedup_news exact + fuzzy ≥ 0.85).
  • Fungsi Keyword & Negation Memindai kata negasi (seperti no, not, despite) dalam jendela 3 kata sebelum kata kunci Bullish/Bearish untuk menyaring berita palsu/tidak relevan.
  • Penyusutan Waktu (Recency Decay) Berita baru memiliki bobot 1.0, sedangkan berita lama menyusut secara eksponensial (waktu paruh 12 jam). Berita di luar 24 jam dibuang.
  • Contoh Hasil Analisis Berita
    • Primary LLM Provider: AgentRouter (GLM-5.2) | Fallback #2: Groq API (qwen/qwen3.6-27b)
    • Replay Anchor Slot: 09:00 UTC (Akumulasi slot 00, 03, 06, 09)
    • Headline: "Gold rallies on high inflation fears" (2 jam lalu)
    → Sentimen: BULLISH | Bobot Waktu: 0.89
    • Headline: "Stronger dollar limits gold upside" (6 jam lalu)
    → Sentimen: BEARISH | Bobot Waktu: 0.70
    • Skor Sentimen Akhir: +0.19 (Bullish Lemah)

Sentiment Step 2: Analisis Kalender

Mendeteksi agenda rilis data ekonomi makro yang dapat memicu volatilitas tinggi pada pergerakan harga emas.

  • Event Berpengaruh Tinggi (High Impact) Memonitor event krusial: NFP (Non-Farm Payroll), FOMC (Fed Rate Decision), CPI (Inflation Data), GDP, dan Powell Speech.
  • Pengecekan Waktu (Proximity) Menghitung jarak waktu (selisih jam dan menit) antara jadwal rilis event dengan waktu perdagangan saat ini.
  • Penarikan Anchor saat Structure Event Saat terjadi Structure Event (CHoCH/BoS/HH/LL) di jam simulasi (misal 10:15 UTC), sistem mengambil data sentimen dari slot 3-harian sebelum terdekat (slot_hour ≤ event_hour, yaitu slot 09:00 UTC).

Sentiment Step 3: Penyesuaian Skor

Menyesuaikan tingkat keyakinan (confidence) transaksi berdasarkan keselarasan sentimen berita dan kedekatan event.

  • Penyesuaian Keselarasan (Alignment) Mencocokkan arah sinyal dari MSA dengan sentimen berita:
    • Searah (Sinyal BUY + Berita Bullish): Skor confidence ditambah (Boost).
    • Berlawanan (Sinyal BUY + Berita Bearish): Skor confidence dikurangi (Penalty).
  • Soft Proximity Penalty (Penyusutan Halus) Mengurangi confidence secara gradual saat mendekati event ekonomi penting:
    • Jarak ~6 jam: -10% dari confidence.
    • Jarak ~1 jam: -25% dari confidence.
    • Jarak <30 menit: -50% dari confidence (maksimal penalti total -15%).
  • Contoh Penyesuaian (Kasus CHoCH Bullish)
    • Sinyal Awal MSA: BUY | Confidence: 0.850
    • Sentimen Berita: BULLISH (+0.19) → Boost: +0.050
    • Event: NFP akan rilis dalam 6 jam → Penalti Halus: -10% (-0.085)
    • Penyesuaian Bersih: +0.050 - 0.085 = -0.035
    • Keyakinan Baru: 0.850 - 0.035 = 0.815

Sentiment Step 4: Veto High Impact

Membatalkan seluruh transaksi ketika waktu rilis berita penting sudah terlalu dekat.

  • Kondisi Veto Keras (Hard Veto) Jika event penting berlabel avoid_trading: True (seperti FOMC atau NFP) dijadwalkan rilis dalam rentang kurang dari 30 menit, transaksi dibatalkan demi keamanan.
  • Hasil Veto Sinyal akhir langsung ditolak dan dialihkan menjadi HOLD, dengan skor keyakinan dipaksa turun menjadi 0.0.
  • Contoh Eksekusi Veto
    • Sinyal MSA: BUY | Event NFP: 15 menit lagi.
    → Veto Keras: TERPICU (Jarak < 30 menit)
    → Keputusan Akhir: HOLD | Confidence: 0.000

Sentiment Step 5: Shadow Mode

Mengeksekusi perhitungan sentimen secara pasif tanpa mengubah transaksi live.

  • Fungsi Shadow Mode Saat shadow mode diaktifkan (shadow_mode: True), penyesuaian confidence dan pembatalan veto tidak memengaruhi sinyal transaksi live.
  • Pemanfaatan Data Log Keputusan sentiment tetap dicatat di objek return shadow_decision dan tersimpan di database SQLite untuk dianalisis dan dibanding-bandingkan dalam pengujian backtesting secara offline.

Consensus Step 1: Pengumpulan Hasil Agen

Menerima parameter arah sinyal dan tingkat keyakinan (confidence) dari sub-agen yang telah selesai beroperasi.

  • Data yang Dikumpulkan • MSA: signal ("BUY"/"SELL"/"HOLD") & confidence (0.0 s.d 1.0)
    • ML: signal ("BUY"/"SELL"/"HOLD") & confidence (0.0 s.d 1.0)
    • Sentiment: final_signal ("BUY"/"SELL"/"HOLD") & final_confidence (0.0 s.d 1.0)

Consensus Step 2: Skor Voting Tertimbang

Mengalikan keyakinan masing-masing agen dengan bobot hak suaranya untuk menghitung skor voting akumulasi.

  • Daftar Bobot Agen • Market Structure: 25% (bobot 0.25)
    • ML Prediction: 40% (bobot 0.40)
    • Sentiment Analysis: 20% (bobot 0.20)
  • Rumus Akumulasi skor[opsi] = ∑ (confidence_agent * bobot_agent) untuk opsi BUY, SELL, dan HOLD.
  • Contoh Simulasi
    • MSA (BUY, 0.85) → 0.85 * 0.25 = 0.2125
    • ML (BUY, 0.90) → 0.90 * 0.40 = 0.3600
    • Sent (BUY, 0.815) → 0.815 * 0.20 = 0.1630
    • Total Skor BUY = 0.2125 + 0.3600 + 0.1630 = 0.7355

Consensus Step 3: Aturan Veto & Bypass

Mengevaluasi kondisi pembatalan darurat (veto) atau penyelamatan sinyal (bypass).

  • Aturan Veto Keras Jika sinyal MSA bernilai HOLD, maka sinyal pemenang langsung ditimpa menjadi HOLD tanpa memedulikan hasil voting lainnya.
  • Aturan Veto Lunak & ML Bypass Jika keyakinan MSA rendah (< 0.60) tetapi ML menghasilkan sinyal aktif dengan expected R:R yang kuat (≥ 1.35), veto dilewati (Bypassed) dan sinyal tetap diijinkan berjalan.

Consensus Step 4: Klasifikasi Tingkat Konsensus

Mengukur persentase kekuatan konsensus akhir dan mengelompokkannya ke dalam tingkat kepercayaan.

  • Kalkulasi Persentase consensus_pct = skor_pemenang / 0.85 (total bobot maksimal).
  • Tingkat Konsensus • ≥ 95% → Unanimous
    • ≥ 80% → Strong
    • ≥ 60% → Moderate
    • ≥ 50% → Weak
    • < 50% → No Consensus

Consensus Step 5: Keputusan Akhir

Mengambil keputusan final apakah sinyal transaksi disetujui untuk dikirim ke bagian manajemen risiko.

  • Syarat Kelayakan (Approval) Sinyal harus berupa BUY atau SELL, dan persentase konsensus wajib mencapai batas minimal 60% (atau lolos bypass veto). Jika tidak dipenuhi, output diubah ke HOLD.
